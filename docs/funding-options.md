# Funding options to verify before applying

Official pages checked on 2026-09-05. These are possible routes, not awards, confirmed eligibility, or applications. Product delivery must not depend on receiving them.

## Core: open-source support

The Codex Open Source Fund advertises a $1 million initiative with up to $25,000 in OpenAI API credits per selected project and rolling review. Credits are not cash. A useful application needs the public repository, a clear project description, the team, and a specific credit-use plan. [OpenAI Codex Open Source Fund](https://openai.com/form/codex-open-source-fund/).

Codex for Open Source is a separate maintainer program. Selected maintainers may receive six months of ChatGPT Pro, API credits, and conditional repository access to Codex Security. The page does not make every public repository eligible or publish one fixed credit award. Do not assume the two programs can be combined. [OpenAI Codex for Open Source](https://openai.com/form/codex-for-oss/).

Core's strongest evidence would be useful reusable code, reproducible tests, actual adopters, active maintenance, and a benchmark showing what additional inference would improve. A public planning file alone is not evidence of adoption.

## Cloud: startup and compute support

| Route | What the official source supports | Planning implication |
| --- | --- | --- |
| OpenAI for Startups | Credits, rate-limit and technical support opportunities through eligible startup and VC-partner paths | Confirm company and referral eligibility; no universal credit amount is assumed. [OpenAI startup program](https://openai.com/business/why-openai/startups/) |
| Anthology Fund | Selective venture investment, technical access, and Anthropic benefits; investments start at $100,000, with terms negotiated individually | This is investment, not an automatic grant. Menlo says Claude need not be the only model; confirm the actual offer terms. [Menlo Anthology Fund](https://menlovc.com/menlo-anthology-fund/) |
| Claude for Startups | Founders can join without VC backing, but credits/extras have narrower eligibility: institutional equity funding, company age within four years, and no previous startup credits | Confirm eligibility separately from joining. Credits apply to the first-party Claude API, not Bedrock or Vertex AI. [Claude for Startups](https://claude.com/programs/startups) |
| AWS Activate | Founders starts at $1,000, with selected participants eligible for up to $5,000; Portfolio advertises up to $200,000 through an Activate Provider | These are conditional ceilings. Company, account, prior-credit, and provider requirements apply. [AWS Activate credits](https://aws.amazon.com/startups/credits/) |

Menlo's page currently gives conflicting Anthropic credit figures: $25,000 in benefit cards and $30,000 in its FAQ. The exact benefit needs written confirmation. Do not state a guaranteed $30,000 award. [Menlo benefits and FAQ](https://menlovc.com/menlo-anthology-fund/).

AWS announced Activate support for third-party Bedrock models, including Anthropic, on **2 April 2024**. A rehosted page dated May 2026 is not the start date of that support. Credits on Bedrock are separate from direct Anthropic API credits. [Original AWS announcement](https://aws.amazon.com/blogs/startups/aws-activate-credits-now-accepted-for-third-party-models-on-amazon-bedrock/).

AWS promotional credits have no cash value and offset only eligible charges before expiry. They do not fund salaries or cover every bill. Track ineligible charges and any excess usage. [AWS credit terms](https://aws.amazon.com/awscredits/).

## Evidence to prepare

1. Show Core and Cloud separately: what is public, what exists, and what is planned.
2. Demonstrate the real game loop with source and build identities, tests, Play, a requested change, rollback, and a permitted remix.
3. Measure model usage, build/storage/delivery costs, repair rate, and cost per accepted playable iteration using ordinary rates as well as promotional credits.
4. Report real creator research and retention with dates and event definitions; keep test runs and demo counters separate.
5. Confirm company, location, funding, referral, license, and account facts. They are currently open inputs, not inferred eligibility.

The owner reports an available server. Until a dated end-to-end trace exists, describe this as an available resource to qualify. A claim that games are already built, sandboxed, and served from Cloud needs direct evidence. No application or contact with these programs is made by this plan.
